# Sprint 3 — Playwright E2E Implementation Plan

> **For agentic workers:** Execute inline. One logical unit per commit. Verify each: `npm run lint && npx tsc --noEmit && npm test && npm run build` all green. `npm run test:e2e` requires BE + FE running.

**Goal:** Cover the Scope C golden paths end-to-end with Playwright using a Page Object Model against a real backend. Catches regressions in cross-page enrichment (lease → tenant card) that unit tests can't see.

**Tech stack:** Playwright 1.x, TypeScript, same ESLint config, semantic locators (getByRole → getByLabel → getByText, no getByTestId).

**Spec reference:** `docs/superpowers/specs/2026-04-16-qa-and-polish-design.md` §3 (Sprint 3), §4.3.

---

## Prerequisites

- BE on :8080 (`make dev`) with Postgres on :5433
- FE on :5173 (`npm run dev`)
- Empty or QA-seeded database — tests clean up after themselves but may collide with pre-existing data

---

## Commit plan

### Step 1 — Install and configure Playwright

- [ ] `cd web && npm install -D @playwright/test`
- [ ] `npx playwright install chromium` (document in plan; don't commit the browser binary)
- [ ] Create `web/playwright.config.ts`:
  - `testDir: './e2e/tests'`
  - `use.baseURL: 'http://localhost:5173'`
  - `webServer` disabled for now — tests assume `make dev` + `npm run dev` already running
  - `projects: [{ name: 'chromium', use: { ...devices['Desktop Chrome'] } }]`
  - `reporter: [['list'], ['html', { open: 'never' }]]`
- [ ] Add scripts to `web/package.json`:
  - `"test:e2e": "playwright test"`
  - `"test:e2e:ui": "playwright test --ui"`
- [ ] Update `web/.gitignore`:
  - `playwright-report/`
  - `test-results/`
  - `blob-report/`
  - `.playwright/`
- [ ] Commit: `chore(e2e): install Playwright and configure test runner`

### Step 2 — Base page and fixtures scaffold

- [ ] `web/e2e/pages/BasePage.ts`: class with `page: Page`, `goto(path: string)`, `header(name: string)` getter using `getByRole('heading')`
- [ ] `web/e2e/fixtures/seed.ts`: axios helpers to create/delete properties, tenants, leases via the BE API. Export `cleanupAll()` that deletes any QA-created records.
- [ ] `web/e2e/fixtures/api.ts`: shared axios instance pointed at `http://localhost:8080`
- [ ] Commit: `chore(e2e): add BasePage and BE seeding fixtures`

### Step 3 — Page objects

- [ ] `web/e2e/pages/DashboardPage.ts`: extends BasePage. `goto()`, `statTile(label)`, `recentLeasesRow(n)`, `addPropertyButton()`
- [ ] `web/e2e/pages/PropertiesPage.ts`: `goto()`, `addPropertyButton()`, `cardByAddress(addr)`, `deleteProperty(addr)` (opens kebab → Delete → Confirm)
- [ ] `web/e2e/pages/PropertyDetailPage.ts`: `goto(id)`, `tab(name)`, `editButton()`, `deleteButton()`, `title()`
- [ ] `web/e2e/pages/TenantsPage.ts`: `goto()`, `addTenantButton()`, `cardByName(name)`
- [ ] `web/e2e/pages/LeasesPage.ts`: `goto()`, `createLeaseButton()`, `cardByAddress(addr)`
- [ ] All methods use `getByRole`/`getByLabel`/`getByText`. Zero `getByTestId` usage.
- [ ] Commit: `chore(e2e): add page object models for all Scope C surfaces`

### Step 4 — Golden path: Properties

- [ ] `web/e2e/tests/properties.spec.ts`:
  - `beforeEach`: cleanup any QA leftovers
  - Create a property via UI, verify card appears on list
  - Navigate to detail, assert address in header, tab through all 5 tabs, assert URL ?tab= updates
  - Open Edit modal, change address, save, verify header updates
  - Delete, confirm, verify navigation back to /properties and card gone
  - `afterEach`: cleanup
- [ ] Commit: `test(e2e): cover properties CRUD golden path`

### Step 5 — Golden path: Tenants

- [ ] `web/e2e/tests/tenants.spec.ts`:
  - Create a tenant via UI, verify card appears
  - Verify email validation: bad email blocks submit
  - `afterEach`: cleanup
- [ ] Commit: `test(e2e): cover tenants create + email validation`

### Step 6 — Golden path: Leases + cross-page enrichment

- [ ] `web/e2e/tests/leases.spec.ts`:
  - `beforeAll`: create one property + one tenant via API fixture
  - Create lease via UI (property + tenant dropdowns) with valid dates
  - Verify lease card appears on `/leases` with correct status pill
  - Navigate to `/tenants` and verify the tenant card now shows property + dates + rent (cross-page enrichment — the original Scope C gap that unit tests couldn't see)
  - Navigate to Dashboard, verify the new lease appears in Recent Leases
  - Verify date validation: end-before-start blocks submit
  - `afterAll`: cleanup lease → tenant → property in that order
- [ ] Commit: `test(e2e): cover lease creation and tenant enrichment`

### Step 7 — Golden path: Dashboard

- [ ] `web/e2e/tests/dashboard.spec.ts`:

  - Stat tiles reflect seeded counts
  - "Your Properties" shows top 3 (or fewer if under)
  - Recent Leases shows the seeded lease
  - Sidebar includes Leases link (regression guard for BUG-004)
  - Add Property link navigates to `/properties`
- [ ] Commit: `test(e2e): cover dashboard stats, links, and sidebar regression`
